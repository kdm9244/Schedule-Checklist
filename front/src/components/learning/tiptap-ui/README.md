# Tiptap UI reference

Official MIT-licensed icons are copied from https://github.com/ueberdosis/tiptap-ui-components/tree/main/apps/web/src/components/tiptap-icons. The original license is included in LICENSE.

PdfRichEditor follows the official Simple Editor's toolbar groups, ghost buttons, separators and color popovers. The official UI implementation is React; its UI structure is adapted for this project's existing Vue/Tiptap editor rather than introducing a second framework. The stored HTML format and allowed color palette remain unchanged.
